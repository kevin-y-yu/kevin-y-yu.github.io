# kevin-y-yu.github.io

Personal academic homepage of Kevin Yu (né Qu). Plain static HTML + CSS, served by GitHub Pages from `main`.

Editing conventions are in [`CLAUDE.md`](CLAUDE.md).

## Preview locally

```bash
python3 -m http.server 8000 --bind 127.0.0.1
# open http://127.0.0.1:8000/
```

Design inspired by [Jon Barron's website](https://jonbarron.info/).
